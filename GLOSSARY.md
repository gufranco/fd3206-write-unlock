# Glossary

**Write stage.** The part of the drive that turns WRITE DATA edges into current through one of two head windings, gated by three conditions. The FD3206P contains one; this firmware replaces its function.
Avoid: write circuit, write logic.

**Heads plan.** The three DDRB values for now, the next edge and the edge after, computed from the toggle state and whether writing is allowed. Type `fdswu_heads_plan_t`.
Avoid: head state table.

**Toggle state.** The single bit, in GPIOR2, that stands in for the 74LS76 flip-flop: it flips on every falling edge of WRITE DATA.
Avoid: phase, parity.

**Conditions.** /READY, /WRITE PROTECT and /WRITE GATE. Writing is allowed only when all three are low.
Avoid: enables, gates.

**Released.** Both head pins are inputs, so the drive's pull-ups hold the heads inactive.
Avoid: off, disabled.

**Pull low or float.** A head pin is either an output at 0 or an input; it never drives high.
Avoid: open collector, when speaking of the ATtiny.

**Piggyback.** The ATtiny soldered directly on top of the FD3206P, pin 1 over pin 1, with no other part.
Avoid: overlay, sandwich.

**Logic layer.** Code that compiles on the host and never includes a hardware header: `src/heads.c`, `src/conditions.c`, `include/fdswu/`.
Avoid: core, pure code.

**Platform layer.** Code that touches registers: `src/main.c`, `src/assert.c`, `src/write_data_edge.S`, `include/port/`.
Avoid: HAL, driver.

**Coverage list.** The addresses of every executable instruction in the firmware's own functions, generated by `tools/list_instructions.py`, which the simulation suite must execute.
Avoid: instruction map.
